# NS Shipping 묶음배송 표시

사용자가 확정한 v29 동작을 이후 비슷한 주문에도 적용한다. 이 규칙은 특정 수령인 이름이나 특정 건수에 한정하지 않는다.

## 묶음 기준과 화면

- `지정` 주문은 전체 배송 주소가 같으면 한 송장으로 묶는다. 주소 앞뒤 공백과 연속 공백을 정규화하며 상세주소가 다르면 별도 송장이다. 수령인 이름만으로 묶지 않는다. 같은 주소의 다른 수령인도 기존 지정 출력과 동일하게 묶는다.
- `지정송하인`은 기존처럼 상품 행별 송장을 유지한다. 지정과 지정송하인을 서로 합치지 않는다.
- 총 건수와 출력 양식별 건수는 상품 행 수가 아닌 실제 출력 송장 수를 표시한다. 화면과 엑셀은 공통 묶음 계산을 사용한다.
- 묶음은 최초 등장 순서대로 정렬하고, 묶음 안 상품은 원본 순서를 유지한다. 떨어진 행의 같은 주소 상품도 같은 묶음에 배치한다.
- 좌측 송장 번호는 1부터 순서대로 부여하고, 묶음의 **첫 상품 줄**에 표시한다. 번호 셀을 `rowSpan`으로 합쳐 가운데에 표시하지 않는다.
- 같은 묶음의 두 번째 이후 상품 줄에는 숫자나 공란 대신 **📦**를 각각 표시한다. 접근성 이름과 툴팁에는 해당 송장 번호와 묶음 상품임을 설명한다.
- 상품명·수령인·수량·출력 양식은 각 상품 행에 계속 표시한다. 상품을 숨기거나 한 줄로 축약하지 않는다.

예: 첫 송장에 상품 1개, 다음 송장에 상품 3개가 있으면 좌측 표시는 `1, 2, 📦, 📦, 3, …`이다. 상품 11행 중 3행만 한 송장으로 합쳐지면 송장은 9건이다. 사용자가 예시 건수를 다르게 말해도 원본과 실제 출력 결과를 확인하고 차이를 설명한다. 숫자를 고정하지 않는다.

## 수정 및 검증

프로젝트에서 다음 파일을 확인한다.

- `src/lib/private-shipping/bundles.ts`: 공통 묶음 계산.
- `src/lib/private-shipping/converter.ts`: 지정·지정송하인 엑셀 출력.
- `src/components/private-shipping.tsx`: 건수, 번호, 📦 표시.
- `tests/private-shipping.test.ts`: 묶음과 출력의 일치 검증.

표시만 수정할 때에는 엑셀 열 구성·상품 내용·수량·기존 묶음 기준을 유지한다. 묶음 계산을 수정하면 화면 건수와 출력 행 수가 일치하는지 확인한다. 첫 줄 번호와 추가 줄 이모티콘은 브라우저에서 확인한다. 첨부 주문 파일이나 개인정보가 담긴 임시 검증 자료는 커밋하거나 배포하지 않는다.

커밋·배포는 프로젝트 `AGENTS.md` 규칙과 현재 요청 범위를 따른다. 이 스킬 자체가 별도 배포나 외부 작업을 승인하지 않는다.
