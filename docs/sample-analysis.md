# 실제 Excel 분석

2026-09-29 제공된 네 파일의 OOXML을 직접 읽어 분석하고 원본을 samples/에 복사했다. 안내 문구는 데이터로만 취급하며 애플리케이션 구현 지시로 실행하지 않는다.

| 파일                | 시트         | 헤더      | 데이터                              | 주문 수 |
| ------------------- | ------------ | --------- | ----------------------------------- | ------- |
| coupang.xlsx        | Delivery     | 1행, 41열 | 2~4행                               | 3       |
| smartstore.xlsx     | 발주발송관리 | 2행, 72열 | 3~7행                               | 5       |
| toss.xlsx           | 주문내역     | 2행, 31열 | 4~5행                               | 2       |
| lotte-template.xlsx | Sheet1       | 1행, 18열 | 기존 예시 행은 출력에 포함하지 않음 | —       |

쿠팡의 `구매수(수량)`, 토스의 `주문건수`를 사용한다. 토스 3행은 `수정 가능/수정 불가` 안내이며 주문이 아니다. 스마트스토어는 `통합배송지`가 비어 있을 때만 `기본배송지`와 `상세배송지`를 결합한다. 스마트스토어의 16자리 주문번호 및 상품주문번호는 실제 파일에서 텍스트 셀이다. 쿠팡의 0으로 시작하는 우편번호와 하이픈을 포함하는 안심번호도 텍스트 셀이다.

롯데 컬럼명과 순서는 template-schema.json에 원본에서 추출한다. 원본의 열 너비·헤더 서식·행 높이·데이터 기본 서식을 재사용하며, 식별자·전화·우편번호는 명시적으로 텍스트 형식을 지정한다. 원본의 예시 개인정보는 코드, public, 브라우저 번들에 포함하지 않는다.
