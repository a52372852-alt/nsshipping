# AdSense 활성화 전 운영 준비

2026-10-02 현재 실제 광고 스크립트는 비활성. 게시자 ID 미제공. 가짜 ca-pub ID, ads.txt, 확인 태그를 만들지 않았다.

## 준비한 구조
- 현재 지원하는 3개 마켓의 고유한 변환 안내, 5개 상세 가이드, FAQ, 서비스 소개, 이용 안내, 개인정보 안내, 문의.
- 문의 주소: marine485@gmail.com (사용자 제공).
- `AdSlot`은 콘텐츠 페이지에서만 사용하며 기본값은 렌더링 없음. preview 모드만 광고 자리 확인용으로 제공. 주문 목록·변환 버튼·다운로드와 분리.
- 공통 root layout과 변환 페이지에는 광고·분석 스크립트를 넣지 않는다. 외부 스크립트는 같은 페이지의 주문 DOM을 읽을 수 있기 때문에 단순히 광고를 버튼 옆에서 멀리 놓는 것으로는 충분하지 않다.

## 실제 광고 연결 순서
1. 사용자가 AdSense 사이트 등록/심사를 진행하고 실제 게시자 ID와 제공된 확인 수단을 준비한다.
2. 공식 정책과 대상 지역에 맞춰 광고 쿠키, 제3자 처리, 선택권과 필요한 동의 절차를 설정한다. 필요한 지역에서는 Google 인증 CMP 적용 여부를 검토한다. 현재 개인정보 문구는 아직 광고를 활성화하지 않은 구현 기준이다.
3. 실제 계정에서 제공한 ads.txt 항목과 확인 코드를 적용한다. 식별자를 추측하지 않는다.
4. 광고는 공개 콘텐츠 전용 영역에서만 실행한다. 자동 광고나 전역 스크립트가 변환 화면으로 확산되지 않도록 한다. SPA 전환 후에도 스크립트가 남을 수 있으므로 광고 페이지 → 변환기 전환 시 문서 전체 새 로드/분리된 문서 경계를 구현하고 검증한다.
5. 광고 라벨, 공간 확보, 모바일 넘침, 버튼 오인, 광고 차단 시 레이아웃을 확인한다. 주문정보를 URL·이벤트·광고 타겟팅에 보내지 않는다.
6. 실제 광고가 로드된 상태에서 변환 화면의 외부 요청과 스크립트가 없는지 재검증한다.

검색 등록/광고 신청/승인/수익 발생은 이번 코드 배포와 별개이며 완료했다고 표시하지 않는다. FAQ 구조화 데이터는 답변의 의미를 설명하기 위한 것이며 검색 결과 확장 표시를 보장하지 않는다. llms.txt가 AI 검색 노출의 필수 요건은 아니다.
